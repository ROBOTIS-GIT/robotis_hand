# HX5-D20 MuJoCo models

The models use the HX5-D20 rev2 meshes already provided by
`robotis_hand_description`. No separate mesh download or ROS process is required.

## Preview

With the MuJoCo Python package installed, run from the repository root:

```bash
python3 -m mujoco.viewer --mjcf=robotis_hand_description/mujoco/hx5_d20_rev2/scene.xml
```

Use `scene_left.xml` or `scene_right.xml` to view one hand. Each hand has 20
position actuators, named after the corresponding `finger_l_joint1`–`20` or
`finger_r_joint1`–`20` joints. The hands are fixed at their bases in these scenes.

The `mujoco` directory is also installed under the package share directory.
Use MuJoCo 3.4 or later; `hx5_d20.xml` composes both hands with `model`/`attach`.

## Attach to another robot

Load `hx5_d20_left.xml` or `hx5_d20_right.xml` as an asset model, then attach
`hx5_d20_left_base` or `hx5_d20_right_base` at the wrist. The palm frame matches
the corresponding rev2 URDF link frame, and all five fingers are its children.
See `hx5_d20_rev2/hx5_d20.xml` for a complete composition example.

Left and right model names, assets and defaults are distinct, so `prefix=""`
preserves the ROS joint names when attaching one of each. Supply a unique prefix
when adding another copy of the same hand. Actuators and contact exclusions are
imported with the hand; do not duplicate them in the parent model.

For a ROS-installed hand, resolve the model file through the
`robotis_hand_description` package share directory in the loading application.
MuJoCo does not resolve `package://` paths itself. The parent model controls
global simulation options such as the timestep and integrator.

## Model settings and source

Adapted from GyuH13's [Add hands model PR #12](https://github.com/ROBOTIS-GIT/robotis_mujoco_menagerie/pull/12)
at commit `0473e6143e84d3431435dd257500d67a027cd556`, under Apache-2.0.

- Retains the PR's finger mesh collisions, contact exclusions and actuator settings:
  `kp=4`, `dampratio=1`, torque limits of ±0.387 N·m, and joint damping of 0.05.
  No additional armature or friction loss is applied.
- Uses the current rev2 URDF inertias (including the palm inertia missing from
  the PR) and joint limits, with existing left/right package meshes.
- Groups each hand under its palm, qualifies shared names for composition, and
  uses `implicitfast` for position-actuator damping.

The gains and damping are simulation parameters. The torque cap is an
approximation at the configured current limit, not a rated torque specification.
The model does not reproduce the hardware current controller, time-based motion
profiles or tactile sensors.

Each palm uses two convex collision meshes to preserve finger clearance.
They are generated by clipping the original `hx5_d20_base_unit.stl` at local
`z = 100 mm` and taking the convex hull of each half. The upper (`_00`) and lower
(`_01`) parts are stored in each hand's `collision/` mesh directory, in the same
millimetre coordinates as the source STL; the MJCF applies a scale of 0.001.
Visual meshes, inertias and contact exclusions are unchanged.
